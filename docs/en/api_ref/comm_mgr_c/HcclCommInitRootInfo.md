## Description

Initializes HCCL based on **rootInfo** and creates an HCCL communicator.

This API supports concurrent calls by multiple threads within the same process, but only in the single-device single-thread scenario. In the single-device multi-thread scenario, concurrent calls are not supported.

As shown in the following figure, concurrent calls of step0 and step1 are not supported. step1 must be executed serially after step0 completes.

![Concurrent calls not supported](figures/comminit_rootinfo.png)

## Function Prototype

```c
HcclResult HcclCommInitRootInfo(uint32_t nRanks, const HcclRootInfo *rootInfo, uint32_t rank, HcclComm *comm)
```

## Parameters

| Parameter | Input/Output | Description |
| --- | --- | --- |
| nRanks | Input | Number of ranks in the cluster. |
| rootInfo | Input | Root rank information, mainly including the IP address and ID of the root rank. It is generated by the [HcclGetRootInfo](HcclGetRootInfo.md) API. |
| rank | Input | Rank ID of the current rank. |
| comm | Output | Pointer to the initialized communicator.<br>For the definition of the HcclComm type, see [HcclComm](./data_type_definition/HcclComm.md). |

## Return Value

[HcclResult](./data_type_definition/HcclResult.md): The API returns **HCCL_SUCCESS** on success, and other values on failure.

## Constraints

The **nRanks** and **rootInfo** of all ranks in the same communicator must be the same.

## Example

```c
uint32_t rankSize = 8;
uint32_t deviceId = 0;
// Generate the rank identifier information of the root node.
HcclRootInfo rootInfo;
HcclGetRootInfo(&rootInfo);
// Initialize the communicator.
HcclComm hcclComm;
HcclCommInitRootInfo(rankSize, &rootInfo, deviceId, &hcclComm);
// Destroy the communicator.
HcclCommDestroy(hcclComm);
```
