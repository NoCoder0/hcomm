## Description

Initializes HCCL based on **nRoot** **rootInfo** entries and creates an HCCL communicator that supports multiple roots (scalable). The **nRanks** ranks in the cluster are divided into **nRoot** groups, each managed by one root, and the roots collaborate through a fully interconnected mesh to complete communicator initialization. The root information of the group to which the current rank belongs is determined by the grouping algorithm based on **nRanks**, **nRoot**, and **rank**.

This API supports concurrent calls by multiple threads within the same process, but only in the single-device single-thread scenario. In the single-device multi-thread scenario, concurrent calls are not supported.

## Function Prototype

```c
HcclResult HcclCommInitRootInfoScalable(uint32_t nRanks, uint32_t nRoot, const HcclRootInfo *rootInfoList, uint32_t rank, uint32_t nExtRoot, const HcclCommConfig *config, HcclComm *comm)
```

## Parameters

| Parameter | Input/Output | Description |
| --- | --- | --- |
| nRanks | Input | Number of ranks in the cluster. |
| nRoot | Input | Number of roots, that is, the number of root groups. The value must satisfy 0 < nRoot ≤ nRanks. |
| rootInfoList | Input | Array of **rootInfo** with a length of **nRoot**, generated by each root node calling [HcclGetRootInfoScalable](HcclGetRootInfoScalable.md). The array subscript is the index of the root, and the entries must be arranged in a fixed order. |
| rank | Input | Rank ID of the current rank. |
| nExtRoot | Input | Reserved parameter. Currently, only 0 can be passed in. It is used for future two-level root expansion based on the current first-level root. |
| config | Input | Communicator configuration items, including the buffer size, deterministic computation switch, communicator name, and communication operator expansion mode. Ensure that the configured parameters are within the valid value range. For details about the meanings and priorities of the parameters in **HcclCommConfig**, see the definition of [HcclCommConfig](./data_type_definition/HcclCommConfig.md).<br>Note: The **config** passed in must be initialized by calling [HcclCommConfigInit](HcclCommConfigInit.md) first. |
| comm | Output | Pointer to the initialized communicator.<br>For the definition of the HcclComm type, see [HcclComm](./data_type_definition/HcclComm.md). |

## Return Value

[HcclResult](./data_type_definition/HcclResult.md): The API returns **HCCL_SUCCESS** on success, and other values on failure.

## Constraints

- The **nRanks**, **nRoot**, **rootInfoList**, and **config** of all ranks in the same communicator must be identical, and the content and order of **rootInfoList** must be exactly the same.
- **nRoot** must satisfy 0 < **nRoot** ≤ **nRanks**.

## Example

```c
uint32_t rankSize = 32;
uint32_t nRoot = 4;
uint32_t deviceId = 0;
HcclRootInfo rootInfoList[4];
// Generate the rank identifier information for each root node.
if (isRootRank) {
    HcclGetRootInfoScalable(&rootInfoList[rootIndex]);
}
// Broadcast rootInfoList to all ranks in the cluster through collective communication.

// Create and initialize the communicator configuration items.
HcclCommConfig config;
HcclCommConfigInit(&config);
// Initialize the collective communicator.
HcclComm hcclComm;
HcclCommInitRootInfoScalable(rankSize, nRoot, rootInfoList, deviceId, 0, &config, &hcclComm);
// Destroy the communicator.
HcclCommDestroy(hcclComm);
```
