# HcclCommConfigCapability

## Description

Defines the configuration information supported during communicator initialization.

## Prototype

```c
typedef enum {
    HCCL_COMM_CONFIG_BUFFER_SIZE = 0,       /* Buffer size of shared data. */
    HCCL_COMM_CONFIG_DETERMINISTIC = 1,    /* Deterministic computation switch. */
    HCCL_COMM_CONFIG_COMM_NAME = 2,        /* Communicator name. */
    HCCL_COMM_CONFIG_OP_EXPANSION_MODE = 3,     /* Communication operator expansion mode. */
    HCCL_COMM_CONFIG_SUPPORT_INIT_BY_ENV = 4,  /* Whether to support using environment variable configuration as the initial value. */
    HCCL_COMM_CONFIG_WORLD_RANKID = 5,  /* Specifies the global rank ID of the current process in the AI framework in the NSLB-DP scenario. This scenario does not apply to Ascend 950PR&950DT products. */
    HCCL_COMM_CONFIG_JOBID = 6,  /* Specifies the unique identifier of the current distributed service in the NSLB-DP scenario, generated by the AI framework. This scenario does not apply to Ascend 950PR&950DT products. */
    HCCL_COMM_CONFIG_ACLGRAPH_ZEROCOPY_ENABLE = 7,  /* Controls whether to enable zero-copy in graph capture mode (aclgraph), effective only for Reduce-type operators. */
    HCCL_COMM_CONFIG_EXEC_TIMEOUT = 8,  /* Communication execution timeout. */ 
    HCCL_COMM_CONFIG_ALGO = 9,  /* Communication algorithm configuration. */
    HCCL_COMM_CONFIG_RETRY = 10,  /* Communication retry configuration. It is not supported by Ascend 950PR&950DT products for now. */
    HCCL_COMM_CONFIG_BUFFER_NAME = 11,  /* Shared CCLBuffer name. It is not supported by Ascend 950PR&950DT products for now. */
    HCCL_COMM_CONFIG_RESERVED              /* Reserved field. */
} HcclCommConfigCapability;
```
