## Description

Generates the rank identification information (**HcclRootInfo**) of the root node and establishes full mesh interconnection listening among root nodes. This API must be called before the HCCL initialization API [HcclCommInitRootInfoScalable](HcclCommInitRootInfoScalable.md) and only needs to be called on each root node.

- This API must be used in a pair with the initialization API [HcclCommInitRootInfoScalable](HcclCommInitRootInfoScalable.md) and cannot be used alone.
- In a multi-root-node (scalable) scenario, the **nRoot** root nodes in the cluster must each call this API to generate their own **rootInfo**. The **rootInfo** entries of all root nodes form **rootInfoList**, which is passed as an input parameter of [HcclCommInitRootInfoScalable](HcclCommInitRootInfoScalable.md) to all ranks in the cluster.

## Function Prototype

```c
HcclResult HcclGetRootInfoScalable(HcclRootInfo *rootInfo)
```

## Parameters

| Parameter | Input/Output | Description |
| --- | --- | --- |
| rootInfo | Output | Identification information of this root node, mainly including the device IP, device ID, and other information, as well as the full mesh interconnection listening port among root nodes. This information must be combined with the **rootInfo** generated by other root nodes to form **rootInfoList**, which is broadcast to all ranks in the cluster for HCCL initialization.<br>For the definition of the **HcclRootInfo** type, see [HcclRootInfo](./data_type_definition/HcclRootInfo.md). |

## Return Value

[HcclResult](./data_type_definition/HcclResult.md): The API returns **HCCL_SUCCESS** on success, and other values on failure.

## Constraints

- Each root node must call this API once. *n* root nodes generate *n* **rootInfo** entries in total, which form **rootInfoList** and are passed to [HcclCommInitRootInfoScalable](HcclCommInitRootInfoScalable.md).
- **rootInfo** generated by all root nodes must be ready before [HcclCommInitRootInfoScalable](HcclCommInitRootInfoScalable.md) is called.

## Example

```c
uint32_t rankSize = 32;
uint32_t nRoot = 4;
uint32_t deviceId = 0;
HcclRootInfo rootInfoList[4];
// Generate the rank identification information for each root node.
if (isRootRank) {
    HcclGetRootInfoScalable(&rootInfoList[rootIndex]);
}
// Broadcast the rootInfoList to all ranks in the cluster through collective communication.
// Initialize the communicator.
HcclComm hcclComm;
HcclCommInitRootInfoScalable(rankSize, nRoot, rootInfoList, deviceId, 0, &config, &hcclComm);
// Destroy the communicator.
HcclCommDestroy(hcclComm);
```
